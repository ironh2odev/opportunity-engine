# Public Repository Safety Checklist

## Safe to Commit

- Mock opportunities and synthetic examples
- Generic prompts and templates
- Reusable workflows and architecture docs
- Database schemas without personal records

## Never Commit

- Real CVs and personal testimonials
- API keys and raw lead exports
- Proprietary paid guides or copyrighted private material
- Personal contact databases

## Enforcement

- `.gitignore` excludes `private/`, `.env`, `.env.local`, and common personal document formats.
- Human approval is mandatory before applications/outreach are sent.
